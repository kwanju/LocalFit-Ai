C. 사람·하드웨어만 검증 가능 — 남은 항목 ❗

C-1

빌드 설치본 실행 + 마이크 (Tauri)

phase 6 / S-4

GUI 설치본 실행·마이크 오디오·프로세스 종료는 헤드리스로 못 함. [Errno 22] stdio 수정은 cargo check까지 끝났으니, 재빌드 후 실제 실행 확인만 남음.

절차

  1. cd ui ; pnpm tauri build (또는 pnpm tauri dev)로 실행
  2. 채팅 세션 시작 → 코치가 뜨는지 (이전 "코치를 불러오지 못했어" 재현 안 됨)
  3. S2S 모드 → 마이크 발화 → STT 인식 → 코치 음성
  4. 트레이에서 종료 → tasklist | findstr python / findstr uv

기대 결과

⚠️ 별개 한계: repo_root()가 컴파일 타임 경로라 설치본을 다른 머신에 배포하면 동작 안 함(ADR-031 번들 후순위). 본인 머신에선 OK.

C-2

능동 알림 — 네이티브 toast

phase 8 / ADR-027

Windows 알림 표시·트레이 동작은 시각 확인 필요. (스케줄 /due·/pending 계산 로직은 단위로 커버됨)

절차

  1. 설정 → 알림 켜기 + 운동 시각을 지금+2분, 리드 0~1분
  2. 창을 트레이로 숨김 → 정시에 toast 관찰
  3. 앱 열기 → ReminderBanner "지금 시작" → 세션
  4. 야간 음소거 시간대를 지금으로 → toast 억제 확인

기대 결과

C-3

Google Calendar — OAuth 동의

phase 9 / ADR-022

브라우저 OAuth 동의 클릭 + 실제 Google 계정 필요. (확답 게이트는 단위로 커버됨) 이제 설정 화면 "캘린더" 섹션에서 GUI로 가능(phase v4-9b) — API 직접 호출 불필요.

절차 (앱 → 설정 → 캘린더)

  1. 설정 → 캘린더 → Google Calendar 연동하기 → 브라우저 동의
  2. "연동됨 ✅" 확인 → 이번 주 운동 캘린더에 등록 → 미리보기 → N건 등록(확인)
  3. Google Calendar 앱/웹에서 이벤트 확인. 앱 재시작 후에도 "연동됨" 유지(자동 갱신)
