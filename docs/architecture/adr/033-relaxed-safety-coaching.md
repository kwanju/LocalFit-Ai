# ADR-033: 안전 코칭 톤 대폭 축소 (홈트레이닝 가정)

- **상태**: Accepted (2026-06-16)
- **관련 ADR**: ADR-013 (능동 코치 — §면책·안전 일부 supersede), ADR-032 (자가보고 우선), ADR-002 (단일 사용자), ADR-023 (컨디션 기반 강도 조절 — 유지)

## 컨텍스트

실사용에서 코치가 **과도하게 보수적·안전 잔소리** 모드였다 — 사용자가 "스쿼트 50회 가능"이라 해도 보수값을 고집하고, 매 제안에 "여유 있게/보수적으로/걱정되면" 같은 헤징을 붙여 코칭이 소심하고 분위기가 무거웠다.

LocalFit 은 **홈트레이닝(맨몸운동, 본인 1인)** 환경이라 헬스장·중량운동 대비 안전 리스크가 매우 낮다. ADR-013 §면책·안전도 이미 "합리적 최소 수준"을 표방했지만, 실제 프롬프트(`SAFETY_SYSTEM_PREFIX` + `ACTIVE_COACH_PROTOCOL` + 첫 세션 컨텍스트)는 그보다 과하게 안전·보수에 기울어 있었다. 사용자 지시로 이를 **대폭 축소**한다.

## 결정

### 축소 (안전·보수 표현 제거)
- **`SAFETY_SYSTEM_PREFIX`**: 한국어 강제(기능적 — 유지)만 남기고 안전 규칙 스택을 1줄로. "평소엔 안전 이야기를 꺼내지 말고 자신감 있게 코칭. 분명한 통증·부상을 말하면 그때만 짧게 무리 말라고 한마디." **응급(119 권유 톤)·전문 의료기관 상담·진단 경고 문구는 프롬프트에서 제거**(의료 진단 안 함만 유지).
- **`ACTIVE_COACH_PROTOCOL` §6 강도**: "초보 여유 있게/실패 지점 금지/보수적 70%/걱정되면" 제거. RPE·RIR 은 **효과(자극) 가이드**로 유지하되, 자신 있으면 실패 가까이(RIR 1~3)까지 밀어붙여도 좋다는 톤으로 전환.
- **첫 세션**(ADR-028, `coach_context._first_session_block` + 프롬프트): "70% 보수적 시작/한계 측정 금지" 제거 → 자가보고 수치를 그대로 기준선으로 쓰고 적당한 첫 세트를 제안(ADR-032 자가보고 우선과 일치).

### 유지 (축소하지 않음 — 명시적 통증/사용자 등록 제약만)
- **`SafetyGuardProcessor` 부상 키워드 자동 처리 + `MSG_INJURY_*` 티어**: **명시적 통증·부상 발화 시에만** 발동하므로 "그때만 짧게 대응"에 부합. 사용자가 완화 범위에서 "톤+자동중단 완화"(옵션 B)를 **선택하지 않았으므로** 메커니즘은 보존한다.
- **ADR-025 부상/제약 메모리 주입**(`⚠️필수 제약 전량`): 사용자가 직접 등록한 실제 제약을 존중하는 것이라 안전 잔소리와 무관 — 유지.
- **ADR-023 컨디션 기반 강도 조절 제안**: 피로/근육통이 높을 때 강도를 낮춘 *제안*은 코칭 기능이지 안전 강박이 아님 — 유지.

## 결과

### 긍정
- 코치가 자신감 있고 결과 지향적으로 코칭, 사용자 자가보고를 신뢰(소심·잔소리 제거).
- 홈트 현실(낮은 리스크)에 맞는 톤. ADR-013 의 "최소 수준" 의도를 실제 프롬프트에 반영.
- 프롬프트 길이 감소(9b 구조화 출력 안정성에도 미세 이득).

### 부정
- 안전망이 명시적 통증 발화(SafetyGuard)에만 남음 — 사용자가 통증을 말 안 하면 코치가 먼저 경고하지 않음. 단일 사용자·홈트 가정에서 수용한 트레이드오프.
- 의료·면책 문구 최소화 — 단일 사용자 본인 책임 가정(ADR-002, 면책은 비핵심: 메모리 `feedback_medical_disclaimer`).

## 대안

| 후보 | 결정 |
|---|---|
| 톤만 완화(옵션 A) | 사용자가 더 강한 축소를 원함 — 미채택 |
| 톤 + SafetyGuard 자동중단 완화(옵션 B) | 명시적 통증 대응까지 풀진 않기로 — 미선택 |
| **시스템 프롬프트 안전 문구 대폭 축소(옵션 C)** | **채택** |
| 안전 전부 제거(통증 발화도 무시) | 명시적 통증엔 최소 대응이 합리적 — 과함, 탈락 |

## supersedes

- ADR-013 **§면책·안전**의 `SAFETY_SYSTEM_PREFIX` 강한 안전 규칙 문구를 본 ADR 이 대체한다. ADR-013 의 나머지(능동 코치 구조·액션·확답 게이트)는 그대로 유효.
